# Weather App 🌦️

A mobile-first weather application built with React Native and Expo Router.

## Features

- 🔍 Search for cities
- 🌍 View real-time weather data
- ❤️ Save favorite locations
- 📍 Use current location
- 🧭 Drawer navigation (Home, Favorites, Location)

## Tech Stack

- React Native
- Expo Router
- Zustand (state management)
- Redux Toolkit Query (API fetching & caching)
- Visual Crossing Weather API

## 📱 Screens

- Home (current weather)
- Search (modal with debounced input)
- Favorites
- My Location

## ⚙️ Installation

```bash
git clone https://github.com/alexandra-riva/weather-native-zustand.git
cd weather-native-zustand
npm install
npx expo start
```
